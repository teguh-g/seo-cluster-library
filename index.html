☁ GitHub Gist Cloud Sync

Sync data antar device via private GitHub Gist. Token disimpan lokal di browser ini saja.
Cara setup pertama kali:
Buka GitHub Token Page → scope gist sudah otomatis dicentang → Generate → copy token
Buka gist.github.com → bikin secret gist dengan filename seo-cluster-library.json dan content []
Copy Gist ID dari URL (bagian setelah username)
Paste keduanya di atas → Save → Push
⚠ Token cuma butuh scope gist. Jangan share token ke siapapun.
